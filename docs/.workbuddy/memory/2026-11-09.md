## IAM 需规文档接口章节改写（docx）
- 文件：docs/IAM身份中心-存量用户组迁移-需求规格说明书_V1.0.docx
- 原因：原文基于"华为云 IAM 身份中心"v1 接口（identity-stores / group-memberships，含 membership_id、identity_store_id、display_name），版本偏新；实际使用 IAM 24.3.0 新版 /v5 接口。
- 映射结果：查询用户组列表 GET /v5/groups；查询用户所属用户组 GET /v5/groups?user_id=；添加 IAM 用户到用户组 POST /v5/groups/{group_id}/add-user；移除用户组中的 IAM 用户 POST /v5/groups/{group_id}/remove-user。
- 关键语义变化：无成员关系 ID（group_id+user_id 定位）、无身份源参数、group_name 直接返回（不再需要名称映射）、AK/SK 签名（Authorization+X-Sdk-Date，临时凭据加 X-Security-Token）、limit 1-200/marker 4-400、错误码 PAP5.0010/0016/0021/0001/0044。
- 改动范围：目录 4 条、第 3 章（3.1-3.8 全部表与正文）、第 4 章流程要点与时序表、第 2 章内联提及、术语表、参考资料表。
- 经验：该 docx 目录是逐条 HYPERLINK/PAGEREF 域，编辑器的 GCP 会计算 instrText 字符，用 python 正则按 w:t 计算偏移会打偏并破坏域；处理目录须按 paraId 直接重建 XML 域条目。

## 修正：接口语义改用 IAM 旧版 /v3（上一版误改成 /v5）
- 用户澄清：需规应对齐 IAM 24.3.0 API 参考的“2 统一身份认证（旧版）”，即 /v3 接口；1.4.x 的 /v5 新版接口全部剔除。
- 最终接口映射：查询用户组列表 GET /v3/groups{?domain_id,name}；查询用户所属用户组 GET /v3/users/{user_id}/groups；添加用户到用户组 PUT /v3/groups/{group_id}/users/{user_id}（204）；删除用户组中用户 DELETE 同路径（204）；可选预检 HEAD 同路径（204 在组内 / 404 不在）。
- 配套语义：X-Auth-Token（全局级 token，scope=domain，24h 可缓存，可由用户自身 token 查询所属组）；无 error_code/request_id，仅 HTTP 状态码；无 limit/marker 分页（links.previous/next 恒 null）；组对象字段 id/name/description/domain_id/create_time；ID 为 32 位十六进制；group 列表支持 name 过滤（≤64 字符）。
- 幂等：PUT/DELETE 天然幂等（204），无 409 分支。
- 技术要点：该 docx 段落常被拆成多 run，且正文段落含表格内段落；改写采用「掩码表格区间后按 w:p 块定位 + 只改 w:t」的纯字符串手术，避免 ET 重新序列化破坏 mc:Ignorable 前缀；改表格须先核对每张表真实列数（3.8 约束表 3 列、时序表 5 列，第 2 列是页面动作）。

- 生成脚本：docs/output/obs-recycle/working/（b1_base 样式与高度模型、b2_layout 版式与目录域、b3_body_a/b 正文、draw_obs_flow.py 流程图、build_obs.py 两遍构建）
- 经验：本机无 Word/LibreOffice，目录页码需自建页面高度模型估算（LH≈2.00 行高系数、TBL_LH≈1.32、表格按行不可拆分页），并用参考文档自身目录页码标定；同时写 w:updateFields=true 让 Word/WPS 打开时自动刷新。
